## Hard constraints

- Python stdlib only, zero dependencies. Must run on stock macOS Python 3.9.6.
  - No `match`, no `X | Y` type unions at runtime, no `tomllib`. Config is JSON.
  - Test with `/usr/bin/python3 -m unittest discover -s tests` on macOS (system 3.9), not the Homebrew `python3` on PATH. Linux: `python3 -m unittest discover -s tests`.
- Runs on macOS and Linux. OS-specific code is isolated in the installer module.
- Claude only in v1. Snapshot carries `agent: "claude"`. No plugin system.
- Terminal (curses) only. No HTML, no listening port.
- Never modify `~/.claude/settings.json` outside the `install` flow, and only after
  showing the exact diff and getting confirmation.

## Hygiene and privacy

- The repo is destined to be public. NO machine names, IPs, account names, usernames or
  home paths in any tracked file. Only exceptions: the maintainer's GitHub handle `oneafrikan`
  and the copyright holder name in `LICENSE`. Test fixtures are synthetic. Per-user rollout (which hub,
  which hosts) lives outside this repo.
- Privacy contract: with any config, no snapshot field contains a cwd, session name,
  project directory name or session id. There is no opt-in in v1.
  Subagent type names (built-in and custom) ARE sent, unfiltered (maintainer decision; documented in the README Privacy section).
- Collector never prints or stores transcript text. It reads `type`, `message.id`, `message.usage`,
  `timestamp` from transcript lines and `agentType` from meta files only.
- Comment code generously: intent, not syntax.
- `.claude/` is local-only (generated by `openspec init`, gitignored, untracked). Never commit it.

## OpenSpec workflow
